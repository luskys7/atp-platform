# 部署故障排查

## 一、当前机器环境检测结果

| 组件 | 要求 | 当前状态 | 影响 |
|------|------|----------|------|
| Docker | 必须（Docker 部署） | **未安装** | 无法 `docker compose up` |
| Java | JDK **17+** | Java **8** | 无法本地编译 Spring Boot 后端 |
| Maven | 本地编译需要 | **未安装** | 无法 `mvn spring-boot:run` |
| Node.js | 前端需要 | v22 ✅ | 前端可本地启动 |
| Python | Agent/执行器 | 3.11 ✅ | Agent 可本地运行 |

**结论：Docker 方式被 Docker 未安装阻断；本地全栈方式被 Java 8 + 无 Maven 阻断。**

## 二、推荐部署路径

### 路径 A：Docker 一键部署（推荐）

1. 安装 [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/)
2. 安装后**重启电脑**，确保 Docker Desktop 处于 Running 状态
3. 在项目根目录执行：

```bat
scripts\deploy.bat
```

或：

```bat
docker compose up -d --build
```

4. 访问 http://localhost ，账号 `admin` / `admin123`

### 路径 B：仅启动前端（预览 UI）

后端未启动时，登录会失败，但可查看页面结构：

```bat
cd frontend
npm install
npm run dev
```

访问 http://localhost:3000

### 路径 C：本地全栈开发

需额外安装：

1. **JDK 17**：https://adoptium.net/temurin/releases/?version=17  
   安装后设置 `JAVA_HOME`，确认 `java -version` 显示 17
2. **Maven 3.9+**：https://maven.apache.org/download.cgi  
   解压后将 `bin` 加入 PATH
3. **MySQL 8 + Redis 7**（或用 Docker 只跑中间件）：

```bat
docker compose up -d mysql redis minio executor
```

4. 初始化数据库：

```bat
mysql -h localhost -u atp_user -patp_pass atp_platform < migrations\001_init_p0.sql
mysql -h localhost -u atp_user -patp_pass atp_platform < migrations\002_init_p1.sql
```

5. 启动后端：

```bat
cd backend-java
mvn spring-boot:run
```

6. 启动前端：

```bat
cd frontend
npm run dev
```

## 三、Docker 部署常见报错

| 报错 | 原因 | 解决 |
|------|------|------|
| `'docker' 不是内部或外部命令` | Docker 未安装或未加入 PATH | 安装 Docker Desktop 并重启 |
| `port is already allocated` | 80/8080/3306 端口被占用 | 关闭占用程序或改 docker-compose 端口 |
| `Cannot connect to the Docker daemon` | Docker Desktop 未启动 | 打开 Docker Desktop |
| `backend` 容器反复重启 | MySQL 未就绪 / Java 构建失败 | `docker compose logs backend` 查看详情 |
| 前端能开但登录失败 | 后端未启动或未连通 | 检查 http://localhost:8080/api/health |
